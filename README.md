# Financial Document Intelligence Agent for SMEs

An AI-powered application that analyzes financial documents and generates meaningful business insights using Generative AI, RAG, and intelligent document processing.

## Features

- Financial document classification
- Profit & Loss analysis
- Balance Sheet analysis
- Invoice analysis
- Automated financial insights
- Generative AI-powered responses
- Streamlit user interface

## Tech Stack

- Python
- Generative AI
- Google Gemini
- LangChain
- RAG
- Streamlit
- Pandas
- Vector Database

## Project Workflow

Upload financial documents → Extract data → Classify documents → Analyze financial information → Generate AI-powered insights

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
